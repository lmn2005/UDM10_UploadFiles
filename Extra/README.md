# Dữ liệu bổ sung

Thư mục này dùng để lưu dữ liệu bổ sung cho quá trình phát triển và kiểm thử:

- Ảnh chụp màn hình.
- Log kiểm thử.
- Dữ liệu test.
- Kết quả stress test.
- Kết quả performance test.
- Sơ đồ kiến trúc.

**Lưu ý:** Không lưu password, secret hoặc dữ liệu cá nhân thật trong thư mục này.
