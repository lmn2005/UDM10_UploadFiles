# Dữ liệu bổ sung

Thư mục này chứa các bằng chứng kiểm thử và tài liệu bổ sung khác:
- Ảnh chụp màn hình.
- Log kiểm thử.
- Dữ liệu test.
- Kết quả stress test.
- Kết quả performance test.
- Sơ đồ kiến trúc.
- Sơ đồ cấu trúc message.

**Lưu ý:** Không lưu password, secret hoặc dữ liệu cá nhân thật trong thư mục này.
