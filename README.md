# UDM10_UploadFiles
Ứng dụng upload nhiều file

## Mô tả
Ứng dụng GUI cho phép kéo thả và upload nhiều file lên Server qua TCP socket.
Đề tài môn Lập trình Ứng dụng Mạng.

## Công nghệ sử dụng
- C# / .NET
- WinForms
- TCP Socket (System.Net.Sockets)
